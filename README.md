# Task Management API

A REST API built with FastAPI for managing tasks.

## Features
- Create tasks
- Get all tasks
- Get a task by ID
- Update tasks
- Delete tasks
- SQLite database
- Pydantic schemas
- SQLAlchemy models
- FastAPI routers

## Tech Stack
- Python
- FastAPI
- SQLAlchemy
- Pydantic
- SQLite
- Uvicorn
